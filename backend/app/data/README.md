# Встроенные сценарии

Файлы здесь (`scenario_ie46_kva.json` и др.) подхватываются **при старте** и **при открытии списка сценариев** (`GET /scenarios`): если записи с таким названием ещё нет в БД, она создаётся автоматически.

## Проверка без входа

- **`GET /health`** — только JSON `{"status":"ok",...}` **без базы** (если не открывается — API не запущен или другой порт, не 8000).
- **`GET /health/db`** — список сценариев из SQLite (встроенный JSON подхватывается здесь же).

Адрес **`/scenarios` в браузере без токена** вернёт 401: нужен вход оператора или Swagger **`/docs`**.

## База данных

По умолчанию SQLite лежит в **`backend/nuclear_support.db`** (абсолютный путь), чтобы данные не «дублировались» из‑за разной папки запуска uvicorn.

Если в `.env` задано `DATABASE_URL=sqlite:///./nuclear_support.db`, лучше **убрать** эту строку или указать полный путь к файлу в `backend/`.

Старый файл `nuclear_support.db` в **корне репозитория** (если остался) — это другая база; при необходимости скопируйте его в `backend/` или удалите и перезапустите сервер (пользователи создадутся заново через `init_db`).
